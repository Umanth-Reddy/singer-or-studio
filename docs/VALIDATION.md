# Validation performed while preparing the repository

- The dataset-free checks recalculated the 96 JVS cells, 84 point contrasts, both scoring arrangements across 200 core model-condition masks, and the ten reconciled confidence intervals.
- From a copy outside the project workspace, the portable scorer matched the full published F2/G1 tables, the original JVS comparison and complete factorial, all CoVox/NUS matched-response and secondary gallery summaries, and the MUSDB18 results when supplied the archived embeddings. The T1 command reproduced its per-response and per-accompaniment scores and intervals.
- The portable renderer accepted the original JVS ZIP and the source fingerprints for CoVox, NUS and the eight selected measured responses. It completed 600 JVS and 1,564 measured-response crops. All 600 regenerated JVS crops matched the archived decoded waveform samples exactly. The original CVSM-ART, CVSM-A and Torres checkpoints passed an inference probe on three JVS crops per encoder. ECAPA and MERT passed a one-crop inference probe. The tested checkpoint files were verified by SHA-256.
- A full new waveform-to-score run of F2/G1, T1 and MUSDB18 was outside this packaging check. The existing independent source render and selected fresh inference are separately recorded in archive/independent and archive/selected-inference. Upstream model downloads were not repeated during packaging.
