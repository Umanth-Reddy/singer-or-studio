# Research archive history

This repository was assembled from dated artifacts preserved in the PS, credible-work-bro and Acta Acustica working trees. The archival commits group real files by experiment or writing milestone. Their Git author dates reflect the latest recorded filesystem modification time in each group. For the public repository timeline, both Git dates reflect the recorded artifact time for each group. This archive was assembled and first published on 2026-11-19. The configured project account is the Git author of the archival imports and assembly. These reconstructed commits are a record of repository changes made during the import. The source files did not have to be committed in this arrangement at the time.

[The source ledger](history-sources.tsv) records the path, timestamp, and SHA-256 of every source and the corresponding imported content. A filesystem modification date is evidence of the archived artifact version. It can differ from first creation, original authorship, or when an experiment started. Some imports replace machine-specific paths or reorganize files for sharing. Earlier implementation versions of the portable scripts are replayed as archival imports followed by the current handoff changes. The early VocalSet technique pilot provides historical context and uses a different endpoint from the paper's main benchmark.
